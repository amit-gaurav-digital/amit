📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem:  Nothing happens when I click Generate
Solution:
  1. Check backend is running (npm run dev in backend folder)
  2. Check OpenAI API key in Settings page
  3. Check .env.local has correct API_URL
  4. Check browser console for errors (F12)

Problem:  "Quota exceeded" error
Solution:
  1. Go to Usage page to check quota
  2. Go to Settings to increase monthly limits
  3. Wait until next month for reset (or adjust limit)

Problem:  Pages not loading
Solution:
  1. Check .env.local file exists
  2. Check backend is running
  3. Clear browser cache
  4. Check JavaScript console for errors

Problem:  Metrics show as 0
Solution:
  1. Backend might be still calculating
  2. Refresh page after generation
  3. Check network tab to see API response
  4. Ensure content was properly generated
